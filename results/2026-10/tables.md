## 3. Derived values (from section 2)

CPU per request: "0.1 s" — the 100 ms × 100 clients run (~1000 req/s with a 0.1 s wait); "1 s" — the 1 s run with the largest number of clients up to 1000 (RoadRunner: 500). Memory per 1000 waits — memory growth at 1 s wait from 100 clients to the largest number up to 1000, and from 1000 to 5000. Base — memory at 100 clients minus 0.1 × growth. In brackets: the slope computed within each pass. The slope mixes concurrency with throughput (more concurrent requests waiting 1 s also means more requests per second) and, for garbage-collected runtimes, the heap policy; it does not carry over to other loads: Node at 100 clients with a 0.1 s wait (about 1000 req/s) uses about 1.35 GiB, twice what the model gives.

## 8. Worked example of the model (sections 4 and 5)

Prices: the hourly prices of c7i/m7i/r7i.xlarge (4 vCPU with 8, 16 and 32 GiB) fitted as vCPU × a + GiB × b give $26.83 per vCPU and $2.66 per GiB per month (730 hours). vCPU = CPU-seconds per second / 0.60 (a 60% target CPU utilisation). Concurrent requests = rate × (wait + 0.01 s). Memory = base × vCPU / 8 + slope × concurrent requests / 1000 (above 1000 concurrent requests, the slope from 1000 to 5000). Ceiling = the lower of 7.5 / CPU per request and the rate at which memory on 8 vCPU reaches 30 GiB.

PHP FPM + nginx, 1000 req/s with a 0.1 s wait (section 3: stack CPU 0.650 ms, DB CPU 1.539 ms, base 30 MiB, 1157 MiB per 1000 waiting requests):

- vCPU: 0.650 ms × 1000 req/s = 0.650 CPU-seconds per second; / 0.60 = 1.084 vCPU.
- Concurrent requests: 1000 × (0.1 + 0.01) s = 110.
- Memory: 30 MiB × 1.084 / 8 + 1157 MiB × 110 / 1000 = 131 MiB = 0.128 GiB.
- Stack: 1.084 × $26.83 + 0.128 × $2.66 = $29.41 per month (section 4: $29).
- Stack + DB: (0.650 + 1.539) / 0.60 × $26.83 + 0.128 × $2.66 = $98.25 (section 4: $98).
- Ceiling with a 1 s wait: CPU limit 7.5 / 0.001201 s = 6 247 req/s; memory at that rate (6 310 concurrent requests) 7.2 GiB ≤ 30 GiB, so the ceiling is 6 247 req/s.

PHP RoadRunner, 1000 req/s with a 0.1 s wait (section 3: stack CPU 0.721 ms, DB CPU 1.511 ms, base 12 MiB, 11770 MiB per 1000 waiting requests):

- vCPU: 0.721 ms × 1000 req/s = 0.721 CPU-seconds per second; / 0.60 = 1.201 vCPU.
- Concurrent requests: 1000 × (0.1 + 0.01) s = 110.
- Memory: 12 MiB × 1.201 / 8 + 11770 MiB × 110 / 1000 = 1296 MiB = 1.266 GiB.
- Stack: 1.201 × $26.83 + 1.266 × $2.66 = $35.58 per month (section 4: $36).
- Stack + DB: (0.721 + 1.511) / 0.60 × $26.83 + 1.266 × $2.66 = $103.15 (section 4: $103).
- Ceiling with a 1 s wait: CPU limit 7.5 / 0.001241 s = 6 045 req/s; memory at that rate (6 106 concurrent requests) 70.2 GiB > 30 GiB, so the ceiling is 495 req/s (RoadRunner's 500 workers: 500 / 1.01 s; memory alone would allow more).
